# Connected Car Platform Overview &#123;#Untitled .concept&#125;

The IoT Connected Car Platform is a cloud-driven system that enables vehicles to communicate with backend services, mobile applications, and external networks in real time.

The IoT Connected Car platform supports real-time telemetry, remote operations, and end-to-end validation of connected features such as safety, infotainment, and autonomous driving assistance. It bridges the physical vehicle with cloud intelligence through a layered, scalable architecture.

## What the Platform Enables &#123;#section_zk1_l2j_cjc .section&#125;

-   Real-time vehicle telemetry collection and visualization
-   Remote command execution \(lock or unlock, engine start or engine stop\)
-   Standards-compliant RF and protocol testing
-   End-to-end connected feature validation
-   Production-scale device onboarding and fleet management

## Integrated Components &#123;#section_bl1_l2j_cjc .section&#125;

The platform integrates the following hardware and software layers:

:   On-vehicle edge devices responsible for collecting sensor data and relaying commands.

**:   Support UWB, 5G NR, and satellite \(NR-NTN\) connectivity standards.

:   REST and GraphQL APIs, data processing pipelines, and device registry.

:   Mobile and web apps for remote control, monitoring, and alerts.

## Primary Use Cases &#123;#section_dl1_l2j_cjc .section&#125;

-   **Fleet Management:** Monitor and manage large vehicle fleets centrally.
-   **Remote Operations:** Issue commands to vehicles from anywhere.
-   **Predictive Maintenance:** Use telemetry trends to anticipate failures.
-   **Safety Compliance:** Validate safety-critical features via digital twin.
