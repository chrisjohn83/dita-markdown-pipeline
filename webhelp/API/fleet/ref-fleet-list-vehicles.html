GET /fleet/vehicles — List All Fleet Vehicles

Retrieves a paginated list of all vehicles registered to the authenticated tenant's fleet, with optional filters for status, group, and vehicle type.

Endpoint

MethodGET
URI Pathhttps://api.connectedcar.io/v1/fleet/vehicles
Auth Scopefleet:read
Rate Limit120 requests / minute per tenant

Authentication

Authorization: Bearer {access_token}
X-Tenant-ID: {tenant_id}

See API Authentication for token acquisition details.

Query Parameters

ParameterType RequiredDescription
statusstringNo Filter by vehicle status. Values: active, inactive, maintenance.
group_idstringNo Filter vehicles belonging to a specific fleet group.
pageintegerNo Page number, 1-based. Default: 1.
limitintegerNo Records per page. Default: 50. Max: 200.
sortstringNo Sort field. Values: vin, last_seen, status. Default: last_seen.

Sample Request

GET /v1/fleet/vehicles?status=active&page=1&limit=3 HTTP/1.1
Host: api.connectedcar.io
Authorization: Bearer eyJhbGciOiJSUzI1NiJ9...
X-Tenant-ID: tenant_abc123
X-Request-ID: 7f3d9c2a-1b4e-4f8a-9d2c-3e5f7a1b9e4d
Accept: application/json
