GET /fleet/vehicles/{vehicleId}/status — Get Vehicle Status

Returns the real-time operational status of a single vehicle, including location, connectivity, engine state, fuel/battery level, and door lock state.

Endpoint

MethodGET
URI Pathhttps://api.connectedcar.io/v1/fleet/vehicles/{vehicleId}/status
Auth Scopefleet:read
Rate Limit300 requests / minute per tenant

Authentication

Authorization: Bearer {access_token}
X-Tenant-ID: {tenant_id}

Path Parameters

ParameterType RequiredDescription
vehicleIdstringYes Unique platform vehicle identifier (e.g., veh_X7K2M9P1).

Sample Request

GET /v1/fleet/vehicles/veh_X7K2M9P1/status HTTP/1.1
Host: api.connectedcar.io
Authorization: Bearer eyJhbGciOiJSUzI1NiJ9...
X-Tenant-ID: tenant_abc123
X-Request-ID: a1b2c3d4-e5f6-7890-abcd-ef1234567890
Accept: application/json

Error Codes

HTTP StatusError Code DescriptionResolution
404VEHICLE_NOT_FOUND No vehicle with the given vehicleId exists in this tenant. Verify the vehicle ID using the List Vehicles endpoint.
403INSUFFICIENT_SCOPE Token missing fleet:read scope. Re-authorize with correct scope.
503VEHICLE_OFFLINE Vehicle TCU is not currently reachable; last known status returned. Check connectivity.last_heartbeat for staleness context.
