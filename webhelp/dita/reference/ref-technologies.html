Supported Technologies

Reference list of all wireless standards, communication protocols, API types, and data storage technologies supported by the IoT Connected Car Platform.

Wireless Technologies

Technology Standard Use Case in Platform
UWB (Ultra-Wideband) IEEE 802.15.4z Precise short-range positioning, digital key, passive entry/start
5G NR (New Radio) 3GPP Release 15+ High-bandwidth telemetry, infotainment streaming, OTA updates
NR-NTN (Non-Terrestrial Network) 3GPP Release 17 Satellite connectivity for remote and off-road vehicle coverage
LTE (4G) 3GPP Release 8+ Fallback cellular connectivity where 5G is unavailable

Communication Protocols

Protocol Type Role in Platform
MQTT Publish-Subscribe Primary telemetry streaming from vehicle TCU to cloud; lightweight, low-overhead
HTTP / HTTPS Request-Response REST API calls, device provisioning payloads, command acknowledgments
gRPC RPC / Streaming High-performance inter-service communication in the cloud processing layer
TLS 1.3 Security Layer Transport encryption for all MQTT and HTTP channels
WebSocket Bi-directional Real-time dashboard data push to web browsers
