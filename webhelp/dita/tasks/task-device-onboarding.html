Onboard a Vehicle Device

Register and provision a new vehicle or TCU on the IoT Connected Car Platform so it can communicate with cloud services and be managed remotely.

Before onboarding a device, ensure the following are in place:

  • A registered and active user account with Device Manager or Admin role.
  • The vehicle's VIN (Vehicle Identification Number) or device QR code.
  • Valid security credentials or certificates for the device.
  • Device firmware version meets the minimum platform requirement.

Device onboarding establishes a secure, authenticated link between a physical vehicle and the platform. Once onboarded, the device can transmit telemetry, receive remote commands, and receive OTA updates. Each device is assigned a unique identity and certificate for secure communication.

  1. Log in to the IoT Control Center dashboard.
    Use your registered account credentials. Ensure MFA is completed if enabled.
  2. Navigate to Device Management > Device Onboarding.
  3. Select the onboarding method.
    OptionDescription
    VIN-based Enter the 17-character Vehicle Identification Number manually.
    QR Code Scan the QR code printed on the TCU or vehicle documentation.
    Bulk / Fleet Upload a CSV file or use the API for batch registration of multiple devices.
  4. Enter the device details in the registration form.
    1. Enter the VIN or Device ID.
    2. Select the vehicle Model and enter the Firmware Version.
    3. Assign the device to an existing fleet or user account.
  5. Upload or assign security credentials.
    Upload the device certificate (.pem or .crt), or allow the platform to generate and provision credentials automatically via OTA provisioning.
  6. Click Initiate Provisioning.
    The platform will generate a unique device identity and push credentials to the TCU.
  7. Verify the device status changes to Active.
    Status transitions: Registered → Pending → Active. If the status shows Failed, refer to the troubleshooting reference.

The device is securely registered, provisioned, and connected to the platform. It will now appear in the Fleet Dashboard and begin transmitting telemetry data. The onboarding event is recorded in the platform audit log.

After successful onboarding:

  • Configure alert thresholds for the new device.
  • Assign the device to the appropriate fleet group.
  • Verify telemetry data is appearing on the dashboard.
