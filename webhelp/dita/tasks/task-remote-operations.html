Execute Remote Commands on a Vehicle

Send a remote command to a connected vehicle and track its execution through the full command lifecycle from dispatch to acknowledgment.

Before executing remote commands:

  • The target vehicle must be onboarded and in Active status.
  • Your account must have the Vehicle Owner, Fleet Manager, or Admin role.
  • The vehicle must be within network coverage (cellular or satellite).
  • Safety constraints must be satisfied (e.g., vehicle must be stationary to unlock doors).

Remote operations allow authorized users to send commands to their vehicle from anywhere through the mobile app or web portal. Every command is authorized, safety- checked, queued, and delivered asynchronously. The platform tracks each command through its full lifecycle and notifies the user of the outcome.

  1. Open the vehicle dashboard in the mobile app or web portal.
    Select the target vehicle from your vehicle list if you manage multiple vehicles.
  2. Tap or click Remote Operations.
  3. Select the command to execute.
    OptionDescription
    Lock Doors Remotely locks all vehicle doors. No safety precondition required.
    Unlock Doors Remotely unlocks doors. Vehicle must be stationary (speed = 0 km/h).
    Engine Start Starts the engine remotely for pre-conditioning. Safety checks applied.
    Engine Stop Stops the engine. Blocked if vehicle is in motion.
    Horn Briefly sounds the horn to help locate the vehicle.
    Flash Lights Flashes the headlights to help locate the vehicle.
  4. Confirm the command in the confirmation dialog.
    A confirmation prompt appears for commands that affect safety (e.g., engine start/stop). Review the details and tap Confirm.
  5. Tap Send Command.
    The command is submitted to the platform and enters the delivery queue.
  6. Track the execution status in the Command Status panel.
    The status progresses through the following states:
    • Sent: Command has been queued in the platform.
    • Delivered: Command has reached the vehicle's TCU.
    • Executed: Vehicle has confirmed successful execution.
    • Failed: Command could not be delivered or executed (reason displayed).
  7. Acknowledge the push notification confirming the command outcome.

The selected command is successfully executed on the vehicle. A confirmation notification is sent to the user, and the command is recorded in the Command History log with timestamp, user, command type, and outcome.

To review a history of all commands sent to the vehicle, navigate to Remote Operations > Command History.
