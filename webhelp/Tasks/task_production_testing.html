Run Production-Scale Testing

Execute high-throughput batch testing across a large fleet of devices to validate readiness for mass production deployment.

Before running production-scale tests:

  • All devices in the batch must be onboarded and provisioned on the platform.
  • Individual device connectivity and E2E validation must be completed per device type.
  • You must have Fleet Manager or Admin role permissions.
  • Sufficient test infrastructure capacity must be confirmed with the platform administrator.

Production-scale testing is designed for manufacturing environments where hundreds or thousands of devices must be validated simultaneously. The platform's parallel test engine executes configured test scenarios across the entire device batch and produces aggregate reports for production yield analysis.

  1. Navigate to Test Center > Production Testing.
  2. Upload the batch device list.
    1. Click Upload Device List.
    2. Select a CSV file containing the device VINs or Device IDs to include in the batch.
    3. Review the parsed device count and verify it matches expectations, then click Confirm.
  3. Configure the test scenarios to execute across the batch.
    Select one or more test scenarios:
    • RF and protocol connectivity
    • Remote command round-trip
    • Telemetry ingestion verification
    • OTA update delivery (optional)
  4. Set the parallel concurrency level.
    Higher concurrency processes more devices simultaneously but requires more infrastructure. The recommended setting is determined by your platform tier. Contact the platform administrator if unsure.
  5. Click Start Production Test Run.
  6. Monitor the batch progress in the Production Test Monitor.
    The monitor displays live metrics:
    • Throughput: Devices tested per minute.
    • Success Rate: Percentage of devices passing all scenarios so far.
    • Failures: Count of failed devices with failure categories.
    • Estimated Completion: Time remaining for the full batch.
  7. Review the completed batch report in the Test Reports tab.
  8. Export the test report for production sign-off and traceability.
    Reports are available in PDF and CSV formats. The report includes per-device pass/fail status, failure categories, and aggregate yield statistics.

All devices in the batch are validated against the configured scenarios. A production test report is generated with aggregate yield data. Devices that fail are flagged for rework, and the results are recorded in the platform audit log.

Review the failure analysis section of the report to identify systematic issues (e.g., a specific firmware version or hardware batch). Re-run failed devices after remediation using the Retry Failed Devices option.
