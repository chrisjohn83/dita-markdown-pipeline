Troubleshooting

Common issues encountered on the IoT Connected Car Platform, their likely causes, and recommended resolutions.

Device and Connectivity Issues

Issue Likely Cause Resolution Escalation
Device not connecting to platform Invalid or expired device credentials / certificates Re-provision the device via Device Management > Re-provision. If credentials have expired, generate new certificates and push via OTA. Platform Admin
Device stuck in Pending status Device has not completed the authentication handshake Verify the device has network connectivity. Check the TCU firmware version meets the minimum requirement. Review audit logs for provisioning error codes. Platform Admin
Weak or intermittent signal RF interference from adjacent wireless modules or poor antenna placement Run RF coexistence test via Test Center. Adjust antenna positioning per hardware integration guide. Check for interference from nearby devices. RF Engineer
Device shows Failed status after onboarding Certificate mismatch or VIN already registered Check the audit log for the specific failure reason. Ensure the VIN has not already been registered. Re-upload the correct certificate and retry provisioning. Platform Admin

Remote Command Issues

Issue Likely Cause Resolution Escalation
Command status stuck at Sent Vehicle is offline or out of network coverage Wait for the vehicle to regain connectivity — the command will be delivered automatically when the connection is restored. Check vehicle location and network coverage map. —
Command status shows Failed Network delay, safety interlock active, or vehicle rejected the command Check the failure reason displayed in the Command Status panel. For safety interlocks (e.g., vehicle in motion), wait for the precondition to be met and retry. —
Unauthorized to send command User role does not have permission for the selected command Contact your Fleet Manager or Platform Admin to review and update your role permissions. Fleet Manager

Telemetry and Data Issues

Issue Likely Cause Resolution Escalation
Dashboard shows no telemetry data Device is offline, or telemetry reporting interval is misconfigured Verify device is Active and online. Check the configured telemetry reporting interval in Device Settings. Review the ingestion service logs for rejected payloads. Platform Admin
Telemetry data appears inconsistent Variation in test environment or sensor calibration drift Use network simulation tools to reproduce consistent conditions. Recalibrate sensors per the vehicle hardware guide. Enable schema validation to identify malformed records. RF / Hardware Engineer

Test and Validation Issues

Issue Likely Cause Resolution
Test results are inconsistent between runs Environmental variation in test setup (temperature, RF background noise) Use the network simulation environment rather than live network for regression testing. Ensure the test cell is shielded from external RF sources.
Production batch test throughput is low Concurrency level set too low, or insufficient platform capacity Increase the parallel concurrency setting. Contact the Platform Admin to confirm infrastructure capacity for the required batch size.

Where to Get Help

  • Review the platform audit log for detailed error codes: Admin > Audit Logs.
  • Contact your Platform Administrator for role or credential issues.
  • Raise a support ticket via the platform Help portal for persistent or unresolved issues.
